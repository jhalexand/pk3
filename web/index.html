Pong Kombat 3 was written in 1997 as a final project for an intro to software engineering course. It ran on Solaris workstations under X and Motif.

By Dave Akers, Jeff Alexander, Elaine Chen, Benoit Hudson and Mike Pelluaer.

This version runs the original game engine, graphics and sounds in your browser.
